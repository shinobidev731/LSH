# Living Stone Hymns (LSH)

A modern, responsive Christian hymnal web application for **The Church of the Living Stone Int'l**, built with React, Vite, and Lucide Icons.

## ✨ Features

- **📖 Complete Hymn Index & Categories**: Browse hymns by number or categorized themes (Praise & Adoration, Morning Hymns, Evening Hymns, Faith & Assurance, etc.) with hymn range badges.
- **🇬🇧 / 🇳🇬 Bilingual Support**: Seamless English ↔ Yoruba lyrics and titles translation with quick-toggle buttons.
- **🎹 Interactive Hymn Tune Player**: Built-in Web Audio API organ synthesizer that plays authentic hymn tunes with live status and playback controls.
- **🌙 System, Light & Dark Themes**: Follows device color scheme by default with manual Light/Dark mode toggles.
- **❤️ Favorites & Reading History**: Easily save favorite hymns and track recently opened hymns (with persistence in `localStorage`).
- **🔍 Quick Search**: Compact expanding search bar allowing search by hymn number, English title, or Yoruba title.
- **📱 Responsive & Mobile-First**: Optimized for all device views and notch safe-areas with Poppins typography.
- **⚙️ Settings & Menu Drawer**: Quick navigation drawer and dedicated settings panel.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/shinobidev731/living-stone-hymns.git

# Navigate to directory
cd living-stone-hymns

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Build for Production
```bash
npm run build
```
